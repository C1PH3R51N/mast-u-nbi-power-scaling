# Power BI Dashboard

This folder contains the static PDF export of the final Power BI report.

## Report Pages

1.  **Overview** --- cohort-level NBI power scaling and neutron
    response.
2.  **Segment Response** --- segment-level NBI, neutron and plasma
    behaviour.
3.  **Shot Detail** --- interactive individual-shot and segment
    analysis.
4.  **Uncertainty & Data Quality** --- within-segment standard deviation
    and coefficient-of-variation analysis.

## Suggested File

``` text
dashboard/
└── MAST-U_NBI_Power_Scaling.pdf
```

The PDF provides a static showcase of the report. Interactive filtering
and shot selection are available only in the published Power BI version.
